# FNF TO SCRATCH CHART CONVERTER

welcome to the fnf to scratch converter!!!

this tool was purely made to convert charts from the real fnf game to scratch as efficently as possible. the converter was intended to run very big charts and push the limits of Scratch. we are planning to compress it to a point where 1 million notes can easily be handled.

this only works in TurboWarp, a scratch modification. you can install it for windows (and i think mac and linux), or you can just use their website.

# how do i modify the source code?

it is easy as pie! 
- download the code
- open turbowarp
- click file on the top left
- click "load from computer"
- find the universal chart sb3 file
- boom! your done :)

# where do i load the chart?

the converter uses SquigglyTuff's chart converter. there are a lot of scratch engines that use them. most commonly AYS engines. you can find a lot on scratch and find what suits best for you. i would recommended just using the default one though made by SquigglyTuff.

be sure your using turbowarp for actually running it.
